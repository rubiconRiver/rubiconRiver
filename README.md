# Hi, I'm Garett

Full-stack developer at [7shifts](https://www.7shifts.com) in Saskatoon. Whether I'm working or hanging out at home, I love building things and solving problems

## Things I've made

**Board games**
- [pax-buttonica](https://github.com/rubiconRiver/pax-buttonica) — Physical RGB turn buttons for Twilight Imperium 4. 6 3D printed buttons built with ESP32s that light up when it's your turn, with a web app to run everything.  

**Tools**
- [gitsave](https://github.com/rubiconRiver/gitsave) — a menu bar app so non-developers can save their work with Git in one click.
- [plant-tracker](https://github.com/rubiconRiver/plant-tracker) — track plants from seed to harvest, with a garden grid, photo timeline, and NFC tags on the real plants.

**Games and toys**
- [tomb-of-the-mask-clone](https://github.com/rubiconRiver/tomb-of-the-mask-clone) — a 2D maze game built with Godot 4.
- [dreamprompter](https://github.com/rubiconRiver/dreamprompter) — turns your weird dreams into real-world tasks and puts them on your calendar.
- [petza](https://github.com/rubiconRiver/petza) — an ESP32 pet project.

## Stack

TypeScript, React, NestJS, Go, Godot, and whatever the project needs.
